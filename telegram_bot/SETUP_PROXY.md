# Настройка прокси для телеграмм бота

## Проблема

Telegram API заблокирован в некоторых регионах. Для работы бота необходимо использовать прокси или VPN.

## Решение

### Вариант 1: Использование публичного SOCKS5 прокси

1. Найдите рабочий SOCKS5 прокси (например, на сайтах free-proxy-list.net, spys.one)
2. Добавьте в файл `.env`:
   ```
   PROXY_URL=socks5://proxy_host:proxy_port
   ```
   Например:
   ```
   PROXY_URL=socks5://123.45.67.89:1080
   ```

3. Если прокси требует авторизацию:
   ```
   PROXY_URL=socks5://username:password@proxy_host:proxy_port
   ```

### Вариант 2: Использование HTTP прокси

```
PROXY_URL=http://proxy_host:proxy_port
```

### Вариант 3: Локальный VPN

1. Запустите VPN на вашем компьютере
2. Бот будет использовать VPN автоматически (PROXY_URL не нужен)

### Вариант 4: SSH туннель (рекомендуется)

Если у вас есть сервер за границей:

```bash
# Создайте SSH туннель
ssh -D 1080 -N user@your-server.com

# В .env добавьте:
PROXY_URL=socks5://localhost:1080
```

## Проверка подключения

```bash
python3 test_connection.py
```

Если видите ✅ - всё работает!

## Запуск бота

```bash
python3 bot.py
```

## Запуск на сервере (за границей)

Самый надёжный способ - разместить бота на сервере за пределами РФ (например, на DigitalOcean, AWS, Hetzner).
