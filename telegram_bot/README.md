# 🤖 Telegram Bot для Referee App

Телеграмм бот для подготовки футбольных судей с полноценным меню и разделами.

## 🚀 Запуск

```bash
cd telegram_bot
pip install -r requirements.txt
python3 bot.py
```

## 📱 Структура бота

### Главное меню

При отправке `/start` открывается главное меню с разделами:

```
⚽️ Добро пожаловать в бота для подготовки футбольных судей!

📖 Правила футбола
📝 Тесты
🎥 Видео-тесты
🏃 Марафон
⭐️ Избранное
📊 История тестов
ℹ️ Помощь
```

### 📖 Правила футбола

- Просмотр всех 17 правил IFAB
- Каждое правило с подробным описанием
- Навигация между правилами

### 📝 Тесты

- **Быстрый тест** - 10 случайных вопросов
- **Тест по правилам** - выбор конкретного правила
- **Экзамен** - 50 вопросов (полный тест)

### 🎥 Видео-тесты

- Анализ игровых ситуаций
- Видео с вопросами по правилам

### 🏃 Марафон

- Ежедневные вопросы
- Статистика прогресса
- Система стриков

### ⭐️ Избранное

- Сохранение важных вопросов
- Тест из избранных вопросов
- Управление избранным

### 📊 История тестов

- Просмотр всех пройденных тестов
- Детальная статистика
- Анализ ошибок

## 🎮 Команды

- `/start` - Главное меню
- `/help` - Справка

## 🔧 Настройка

### Токен бота

Создайте файл `.env`:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### Прокси (опционально)

Если нужен прокси для обхода блокировок:
```
PROXY_URL=socks5://host:port
```

## 📊 Интеграция с приложением

Бот использует те же JSON файлы, что и Flutter приложение:
- `assets/json/` - правила и тесты
- `assets/clips/` - видео для тестов

## 🐛 Отладка

Логи бота сохраняются в `bot.log`

Проверить статус:
```bash
ps aux | grep bot.py
```

Остановить:
```bash
killall -9 Python
```
