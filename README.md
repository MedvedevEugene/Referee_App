# 🏟️ Referee App - Приложение для судей по футболу

Мобильное приложение для подготовки и тестирования судей по футболу, разработанное на Flutter.

## 📱 Описание проекта

Referee App - это комплексное решение для судей по футболу, включающее:

- **Тестирование по правилам** - 17 глав с детальными вопросами
- **Марафон тесты** - 409 вопросов на выносливость и скорость
- **Избранные вопросы** - персонализированная подготовка
- **История тестов** - отслеживание прогресса и результатов
- **Календарь событий** - планирование матчей и тренировок
- **Правила игры** - полный справочник с иллюстрациями

## 🚀 Технологии

- **Frontend**: Flutter 3.29.0
- **Язык**: Dart
- **Платформы**: iOS, Android, Web
- **Архитектура**: Provider (State Management)
- **Тестирование**: Flutter Test Framework
- **Хранение**: SharedPreferences, Local Assets
